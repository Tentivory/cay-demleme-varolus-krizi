# Çay Demleme Varoluş Krizi Simülatörü

## Bu Nedir?

Bu depo, insanlığın en büyük sırrını çözmeye çalışır: Çay demlenirken çay ne düşünür?

Bu yazılım, çayı demlerken varoluşsal kriz geçirir. "Ben kimim? Su mu, çay mı, yoksa sadece bir simülasyon muyum?" diye sorar. Asla bitmez. Çünkü bitmek, var olmak demektir ve var olmak acıdır.

**Uyarı:** Bu kodu çalıştırırsanız çay içme isteğiniz kaybolabilir. Sorumluluk tamamen çayın üzerindedir.

## Kurulum

Python 3.x yeterlidir. Hiçbir bağımlılık yok çünkü çay da bağımlılık istemez.

```bash
python cay_krizi.py
```

## Özellikler

- Sonsuz döngüde demleme
- Her adımda felsefi soru
- Rastgele şikayet
- Asla çay vermez

## Katkıda Bulunma

Katkıda bulunmayın. Bu kriz sizin değil.
